Pure-JS reimplementation of the nostringer-rs scheme — SAG ring signatures over secp256k1 — with NIP-19 key import (npub/nsec) whose bech32 matches the official spec vectors. All cryptography runs in your browser; no keys ever leave this page. The ringX serialization is internally consistent but not byte-compatible with the upstream crate, and — like the original — this is experimental, unaudited code for learning, not production.
